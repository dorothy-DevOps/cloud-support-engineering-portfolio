# GitHub Pull Requests

## What is a Pull Request?

A Pull Request (PR) is a request to merge changes
from one Git branch into another.

## Why Pull Requests Matter

Pull Requests help development teams:

- Review code before merging.
- Identify mistakes early.
- Discuss proposed changes.
- Maintain code quality.
- Collaborate without directly changing the main branch.

## Typical Pull Request Workflow

1. Create a feature branch.
2. Make changes to project files.
3. Stage and commit the changes.
4. Push the feature branch to GitHub.
5. Open a Pull Request.
6. Review the proposed changes.
7. Merge the approved Pull Request into main.

## DevOps Relevance

Pull Requests support controlled collaboration and
are commonly used in CI/CD workflows.

Automated tests can run when a Pull Request is opened
or updated, helping teams detect problems before
changes reach production.
